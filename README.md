# 会議ノート

会議の録音の文字起こしとホワイトボードの写真から、議事録を自動でつくるアプリ。

## つくった理由

ゼミのプロジェクトで、一度決めたことが後から巻き戻る問題が起きていた。
「前はこう言っていた」と指摘されても記録が残っておらず、同じ議論を何度も繰り返していた。

市販のAI議事録ツールをいくつか調べたが、どれも「決まったこと」は要約する一方で、
**「検討したが採らなかった案と、その理由」は記録しない**。
実際に困っていたのはそこだったため、自分たちで作ることにした。

## 特徴

**1. 採らなかった案とその理由を残す**
議論のループを防ぐための中心的な機能。

**2. 出力を2層に分ける**
議事録は長くなると読み返されない。そこで出力を分けた。

- LINEにそのまま貼る短い版（10行以内、記号なし）
- あとで読み返す詳しい版（開閉式。理由やロジックはこちら）

**3. 前回の持ち越しを自動で引き継ぐ**
前回の記録から自動で入力される。次の会議がすぐ始められる。

## 使い方

1. 会議日と「今日のゴール」を入れる
2. 文字起こしを貼る（iPhoneのボイスメモの文字起こし機能を使用）
3. ホワイトボードの写真を選ぶ
4. 「議事録をつくる」を押す

## つくる過程でぶつかった問題

| 症状 | 原因 | 対応 |
|---|---|---|
| 写真を選んでも反映されない | iPhoneのHEIC形式が読み込めていた | 形式を判定して処理を切り替え。失敗時は理由を画面に表示 |
| 途中で止まる | 入力ではなく**出力**が上限を超えていた | 決定・棄却・持ち越しを3回に分けて書き出す |
| 長い文字起こしが通らない | 1回で全部読もうとしていた | 2万字ずつに分割し、要点を次に引き継ぐ方式に変更 |
| 進捗が分からず不安 | 段階ごとの番号がばらばらだった | 全体の通し番号に統一 |

いずれも実際に使う中で出た問題。最後の1件はチームからの指摘。

## 構成

- 画面：React + Vite
- サーバー：Vercel Functions（APIキーをここで保持し、ブラウザには渡さない）
- 生成：Claude API

## 動かし方

```
npm install
npm run dev
```

環境変数 `ANTHROPIC_API_KEY` が必要。

## やらなかったこと

- **音声ファイルからの文字起こし**：iPhoneの標準機能で足りるため
- **ログイン機能**：当面はチーム内で使うため、複雑さに見合わないと判断
- **複数チーム対応**：使われ方が固まる前に作ると手戻りが出ると判断
